# Security policy

Report suspected vulnerabilities privately to the repository maintainers. On GitHub, use **Security → Report a vulnerability** if available. If private reporting is unavailable, ask a maintainer for a private contact channel before sharing details.

Include the affected plugin and DSH versions, the impact, and reproduction steps using a disposable profile and synthetic messages. Redact conversation content, tokens, cookies, API keys and local account paths from attachments.

The authenticated same-origin HTTP routes and the separation between the source session and its children are security-sensitive. Mention which operation and session boundary were involved so maintainers can reproduce the issue.
